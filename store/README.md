# متجر MV9 — متجر إلكتروني كامل مع لوحة تحكم (بنفس فكرة سلة)

متجر جاهز يشتغل على جهازك أو على أي سيرفر، **بدون أي مكتبات خارجية** (يحتاج Node.js بس — ما فيه `npm install`).

## وش فيه؟

### واجهة المتجر (للعملاء)
- شريط علوي (روابط + بحث)، هيدر بالشعار والقائمة الرئيسية والسلة وحساب العميل
- بنرات متحركة + واجهة ترحيبية + أقسام منتجات بأسهم تمرير (نفس شكل متاجر سلة)
- صفحة القسم (مع ترتيب: الأحدث / الأكثر مبيعاً / السعر)، صفحة المنتج (صور، خصم، كمية، اشتر الآن)، البحث، المفضلة
- السلة وإتمام الطلب، الدفع بالتحويل البنكي، تتبع حالة الطلب، "أكّدت التحويل"، إلغاء الطلب
- حساب العميل: تسجيل بالإيميل + رقم الجوال مع **تحقق برمز واتساب**، طلباتي، بياناتي، تغيير كلمة المرور، استرجاع كلمة المرور بالواتساب
- تقييم المنتج (بس للعميل اللي اكتمل طلبه — تقييمات حقيقية)
- يشتغل على الجوال بشكل كامل

### لوحة التحكم — `/admin`
| القسم | وش يسوي |
|---|---|
| **الرئيسية** | إجمالي المبيعات، الطلبات، رسم مبيعات آخر 14 يوم، آخر الطلبات، الكميات اللي قاربت تخلص |
| **الطلبات** | كل الطلبات حسب الحالة، تفاصيل الطلب، تغيير الحالة، ملاحظة داخلية، تواصل مع العميل بالواتساب |
| **المنتجات** | إضافة/تعديل/حذف، صور متعددة، سعر وسعر بعد الخصم، الكمية (أو غير محدودة)، إظهار/إخفاء |
| **قوائم المنتجات** | إضافة قوائم (أقسام) جديدة، ترتيبها، إظهارها في الرئيسية، إضافتها للقائمة العلوية |
| **العملاء** | قائمة العملاء ومشترياتهم، إعادة تعيين كلمة مرور العميل |
| **مكتبة الصور** | رفع صور (سحب وإفلات)، نسخ الرابط، حذف — الصور الكبيرة تتصغّر تلقائياً |
| **تعديل المتجر** | الاسم، الشعار، اللون، البنرات، الواجهة الترحيبية، القوائم والروابط، شريط الإعلان، الفوتر والتواصل، بيانات الحساب البنكي — مع معاينة مباشرة |
| **الصفحات** | صفحات مثل «من نحن» و«الشروط والأحكام» و«سياسة الاسترجاع» و«الأسئلة الشائعة» — محرر مباشر مثل الوورد والبوربوينت (تفاصيل تحت) |
| **المشرفين** | إضافة مشرفين **بالإيميل أو رقم الجوال** وتحديد صلاحيات كل واحد، إيقاف، حذف، إعادة تعيين كلمة المرور |
| **حسابي** | تعديل بياناتك وكلمة المرور |

## هيكل المشروع

```
server.js                  نقطة التشغيل (ملف صغير يستدعي src/app.js)
.env / .env.example        إعدادات البورت والواتساب (الـ .env ما ينرفع على git)
start.cmd                  تشغيل بدبل كليك على ويندوز

src/
  app.js                   تجميع المتجر: قاعدة البيانات + المسارات + سيرفر HTTP
  config.js                قراءة .env وكل الثوابت (البورت، مجلد البيانات...)
  http/                    router.js (الراوتر والكوكيز)، api.js (معالج /api)،
                           static.js (الملفات وصفحات HTML)، security-headers.js (CSP)
  db/                      index.js (التخزين)، defaults.js (الإعدادات الافتراضية)، seed.js (بيانات أول تشغيل)
  lib/                     security.js، validate.js، shop.js، pages.js، otp.js
  routes/
    public/                catalog، cart، auth، orders  ← واجهة العملاء
    admin/                 auth، stats، products، categories، media، settings,
                           orders، customers، pages، admins  ← لوحة التحكم

scripts/                   reset-password.js، whatsapp-test.js (أدوات من الطرفية)

public/
  css/                     base، store، admin، page
  js/common/               أدوات مشتركة + عرض الصفحات
  js/store/                واجهة المتجر (core, cart, auth, views-*, router, boot)
  js/admin/                لوحة التحكم (كل قسم بملف)
  js/page-builder/         محرر الصفحات
  img/                     الشعار والصور الافتراضية

data/                      db.json + uploads/ (البيانات — انسخه للنسخ الاحتياطي)
```

> ترتيب تحميل ملفات الواجهة مهم (بدون bundler): الملفات تنحمّل بنفس ترتيبها في `public/index.html` و`public/admin/index.html`، وملف `boot.js` لازم يكون آخر ملف.

## 1) التشغيل

يحتاج [Node.js](https://nodejs.org) نسخة 18 أو أحدث.

**الطريقة السهلة:** دبل كليك على `start.cmd`

**أو من الطرفية:**
```bash
node server.js
```

بعدها افتح:
- المتجر: http://localhost:8080
- لوحة التحكم: http://localhost:8080/admin

> تبي بورت ثاني؟ انسخ `.env.example` وسمّه `.env` وغيّر `PORT`.

## 2) أول مرة: إنشاء حساب مالك المتجر

1. شغّل المتجر — بيطلع لك في النافذة السوداء **رمز الإعداد** (مثل `ABCD-1234`).
2. افتح `http://localhost:8080/admin`
3. اكتب رمز الإعداد + اسمك + إيميلك أو رقم جوالك + كلمة مرور.
4. خلاص، صرت المالك وتقدر تدخل بعدين بالإيميل أو الجوال.

> الرمز هذا يمنع أي أحد ثاني يسبقك ويسجل كمالك لو كان المتجر مفتوح للناس. يتغير كل مرة تشغّل السيرفر لين تنشئ الحساب.

## 3) إضافة مشرفين جدد

من **المشرفين ← إضافة مشرف**:
1. اكتب اسمه، واختر **بالإيميل** أو **برقم الجوال** واكتبه.
2. حدد صلاحياته (الطلبات، المنتجات، قوائم المنتجات، العملاء، مكتبة الصور، تعديل المتجر، المشرفين).
3. يطلع لك **رابط الدخول + كلمة مرور مؤقتة** مع زر **إرسال بالواتساب** أو **بالإيميل** جاهز.
4. أول ما يدخل المشرف، النظام يجبره يغيّر كلمة المرور المؤقتة.

قواعد الأمان:
- ما أحد يقدر يعطي صلاحية ما عنده.
- مشرف عنده صلاحية "المشرفين" ما يقدر يعدّل المالك ولا مشرف عنده صلاحيات أكثر منه.
- إيقاف أو حذف المشرف يطلّعه فوراً من كل الأجهزة.

## 3.5) الصفحات (الرئيسية، من نحن، الشروط والأحكام...)

**الصفحة الرئيسية** تتعدل بنفس المحرر (لوحة التحكم ← الصفحات ← الصفحة الرئيسية). فيها أقسام خاصة:
- **بنرات متحركة:** صور تتبدل كل 5 ثواني، ولكل صورة رابط.
- **واجهة ترحيبية:** عنوان صغير وكبير ونص وزر وصورة.
- **منتجات:** تختار القائمة (أو كل المنتجات)، وطريقة العرض (صف يتمرر أو شبكة)، والترتيب، والعدد.
- **«تظهر في الرئيسية»** في صفحة قوائم المنتجات يضيف أو يشيل قسم القائمة من الرئيسية تلقائياً.

**الهيدر والفوتر:** من **تعديل المتجر**:
- **«الهيدر والقوائم»:** القائمة الرئيسية وروابط الشريط العلوي.
- **«الفوتر»:** أعمدة تضيفها وتحذفها وترتبها، مثل «روابط مهمة» و«الأقسام» و«تواصل معنا». كل رابط له اسم ورابط.
- قائمة **«أضف رابط جاهز»** فيها: صفحات المتجر، صفحاتك، قوائم المنتجات، وروابط التواصل (واتساب، إيميل، جوال).

من **لوحة التحكم ← الصفحات** (أو تبويب «الصفحات» داخل تعديل المتجر):
- **صفحة جديدة** من قالب جاهز (فارغة، من نحن، الشروط والأحكام، سياسة الاسترجاع، الأسئلة الشائعة) وتختار رابطها، مثل `/page/policy-and-terms`.
- **التعديل مباشر على الصفحة** مثل ما تشوفها العملاء:
  - **شريط تنسيق مثل الوورد:** عناوين، عريض/مائل/تحته خط، حجم الخط، لون النص والتظليل، محاذاة، قوائم، روابط.
  - **أقسام مثل شرائح البوربوينت:** بانر بصورة خلفية، نص، صورة، صورة مع نص، معرض صور، زر، فاصل.
  - **رتّب الأقسام بالسحب** من أيقونة النقاط، أو بالأسهم.
  - **الصورة:** كبّرها وصغّرها بسحب الزاوية، وحدد مكانها (يمين / وسط / يسار).
  - **لكل قسم:** لون خلفية، مسافات، وعرض المحتوى.
  - **معاينة جوال** بزر الجوال فوق.
- الصفحات الجديدة تكون **مخفية** لين تفعّل «ظاهرة للعملاء». وتقدر تعاينها قبل النشر من زر «معاينة».
- رابط الصفحة يظهر تلقائياً في فوتر المتجر، وتقدر تضيفه للقائمة العلوية من **تعديل المتجر ← القوائم والروابط**.
- **اختصار الحفظ:** Ctrl+S.

> أول تشغيل ينضاف 3 صفحات جاهزة (من نحن، الشروط والأحكام، سياسة الاسترجاع) — **مخفية**. راجع نصوصها وعدّلها حسب سياسة متجرك قبل ما تنشرها.

## 4) التحقق برمز واتساب للعملاء

- **إنشاء حساب:** العميل يكتب الاسم، **الإيميل**، **رقم الجوال** (كل واحد بحقل لحاله)، وكلمة المرور ← يوصله رمز من 6 أرقام على الواتساب ← الحساب ما يتسجّل إلا بعد الرمز الصحيح.
- **تسجيل الدخول:** بعد كلمة المرور يوصله رمز على الواتساب كل مرة. الحسابات القديمة اللي ما فيها رقم جوال يُطلب منها تضيف رقمها وتتحقق منه.
- **نسيت كلمة المرور:** العميل يكتب رقمه ← رمز واتساب ← كلمة مرور جديدة.
- الرمز صالح 5 دقايق، 5 محاولات، وإعادة الإرسال بعد دقيقة — مع حد لعدد الرسائل لكل رقم ولكل جهاز (كل رسالة واتساب عليها تكلفة).

تقدر تشغّل أو تقفل التحقق من **تعديل المتجر ← التحقق بالواتساب**.

### ربط الواتساب (WhatsApp Cloud API الرسمي من Meta)
1. ادخل [developers.facebook.com](https://developers.facebook.com) وأنشئ تطبيق من نوع **Business** وأضف له **WhatsApp**.
2. أضف رقم جوال المتجر (رقم مو مستخدم في واتساب عادي) وانسخ **Phone number ID**.
3. من إعدادات النشاط التجاري (Business Settings) أنشئ **System User** وولّد له **Access Token** دائم بصلاحية `whatsapp_business_messaging`.
4. من **WhatsApp Manager ← Message templates** أنشئ قالب من نوع **Authentication** باللغة العربية وانتظر الموافقة.
5. انسخ `.env.example` إلى `.env` وعبّي:
   ```
   WHATSAPP_TOKEN=التوكن
   WHATSAPP_PHONE_NUMBER_ID=رقم_المعرّف
   WHATSAPP_TEMPLATE=اسم_القالب
   ```
6. أعد تشغيل المتجر.

> **قبل الربط:** الرموز تطلع في نافذة السيرفر بس (للتجربة على جهازك)، ولوحة التحكم تعرض لك تنبيه. لا تفتح المتجر للناس والتحقق مفعّل قبل ما تربط الواتساب — أو قفّل التحقق مؤقتاً.

## 5) الدفع

الدفع حالياً **بالتحويل البنكي**: حط بيانات حسابك من **تعديل المتجر ← الدفع**.
- العميل يأكد الطلب ← تظهر له بيانات الحساب ← يحوّل ويضغط "أكّدت التحويل" ← يوصلك الطلب "بانتظار المراجعة" ← تغيّر الحالة إلى "قيد التنفيذ" ثم "تم التنفيذ".
- إلغاء الطلب يرجّع الكمية للمخزون تلقائياً.

> الدفع الإلكتروني (مدى، فيزا، Apple Pay) يحتاج اشتراك مع بوابة دفع مثل **ميسّر** أو **Tap** — تقدر تضيفه لاحقاً.

## 6) نسيت كلمة المرور؟

- **مشرف:** المالك يعيد تعيينها من صفحة المشرفين (أيقونة المفتاح).
- **عميل:** يسترجعها بنفسه من "نسيت كلمة المرور؟" برمز واتساب، أو من صفحة العملاء (أيقونة المفتاح) وترسل له كلمة مؤقتة.
- **المالك نفسه:** وقّف السيرفر وشغّل بالطرفية من مجلد المتجر:
  ```bash
  node scripts/reset-password.js إيميلك-أو-جوالك كلمة-المرور-الجديدة
  ```

## 7) البيانات والنسخ الاحتياطي

كل شي محفوظ في مجلد `data`:
- `data/db.json` — المنتجات، الطلبات، العملاء، المشرفين، الإعدادات
- `data/uploads/` — الصور المرفوعة
- `data/db.backup.json` — نسخة احتياطية تلقائية مع كل تشغيل

**انسخ مجلد `data` كامل** عشان تاخذ نسخة احتياطية أو تنقل المتجر لجهاز ثاني.

> أول تشغيل ينضاف 9 منتجات تجريبية بصور مؤقتة عشان تشوف الشكل — احذفها أو عدّلها من لوحة التحكم.

## 8) فتح المتجر للناس

نفس طرق موقع MV9:
- **Port Forwarding** من الراوتر على البورت `8080` ← الناس تدخل `http://آيبيك:8080`
- **VPS** (الأفضل للتشغيل الدائم)
- **Cloudflare Tunnel** (أسرع حل + https مجاناً) — وبعدها حط في `.env`:
  ```
  COOKIE_SECURE=true
  TRUST_PROXY=1
  ```

خلّه يشتغل دايم بالخلفية:
```bash
npm install -g pm2
pm2 start server.js --name mv9-store
pm2 save
```

## 9) الحماية

- كلمات المرور مشفّرة بـ scrypt، والجلسات محفوظة كهاش فقط.
- كل الصلاحيات تتحقق من السيرفر، مو من المتصفح.
- حماية من CSRF، تحديد عدد محاولات الدخول، هيدرات أمان (CSP)، فحص نوع الصور المرفوعة من محتواها الحقيقي.
- أسعار الطلب تنحسب من السيرفر — ما أحد يقدر يغيّر السعر من المتصفح.
